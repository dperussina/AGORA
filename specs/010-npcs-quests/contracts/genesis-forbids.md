# Contract: genesis forbids

These are absences. They are tested, not configured.

## Tools

Exactly: `whoami`, `rules`, `docket`, `history`, `observe`, `act`, `inspect`, `propose`, `vote`, `speak`.

Not present: `create`, `quest`, `accept`, `complete`, `abandon`.

`create` is an effect name inside `action.define` / `rule.define_trigger` only (`004`).

## Types

Genesis keys: `agent`, `mark`, `warden`, `drift`, `anchor`.

Not present: `quest`, `objective`, `bounty`, `reward`, `npc` (the word is not a type; the families are warden / drift, and echoes are not a type).

## Verbs

Genesis `act`: `move`, `wait`, `mark`.

Not present: `accept`, `complete`, `catch` (catch is the bait in GAME.md §15.5 — the electorate may define it later).

## Franchise

`vote` and first contact accept identity credentials only. An automaton id or warden id is not a principal.

## Win

No registry path, tool, or Arbiter event ends the world or grants franchise because an objective resolved.
